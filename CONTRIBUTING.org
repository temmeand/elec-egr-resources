#+title: Contributing

* Contributing

The site is built with Hugo. The resource links in =ee2301.org= are the
source for the rendered resources page; Emacs and ox-hugo export that
Org file before Hugo builds the site. Docker provides the same build
tools for local preview and GitHub Pages deployment.

With Docker Desktop installed, start the local preview from the
repository root:

#+begin_src sh
docker compose up --build
#+end_src

Open [[http://localhost:1313/elec-egr-resources/]]. The preview is bound
to localhost, exports =ee2301.org=, and serves the site from a
restricted container; stop it with =Ctrl+C=.

*** Adding Org pages and links
Create a page from the repository root with a title:

#+begin_src sh
./scripts/new_org_page.sh "Digital Logic Resources"
#+end_src

This creates =digital-logic-resources.org= in the repository root from
[[file:scripts/templates/org-page.org][=scripts/templates/org-page.org=]].
With no title argument, the script uses today's date (=YYYY-MM-DD=) as
both the page title and filename:

#+begin_src sh
./scripts/new_org_page.sh
#+end_src

The script transliterates the title into a lowercase, hyphen-separated
Hugo slug and filename, and will not overwrite an existing file. Add
resource links using Org syntax, for example:

#+begin_src org
- [[https://example.org/resource][Example resource]]
#+end_src

The page exports to =content/resources/digital-logic-resources.md= and
appears at =/elec-egr-resources/resources/digital-logic-resources/=. The
Markdown file is generated by the exporter and should not be edited or
committed. Run =docker compose up --build= to preview new content; the
Pages workflow exports all root-level Org files when building.

To link to another Org page from an Org page, use Hugo's =relref=
shortcode in an ox-hugo export snippet. The target is the generated
Markdown path relative to =content/=:

#+begin_src org
@@hugo:[Digital logic resources]({{< relref "resources/digital-logic.md" >}})@@
#+end_src

Use ordinary Org links for external resources. To make a new page
visible from the homepage, add a link in =layouts/index.html=; to add it
to the site-wide navigation, edit the navigation in
=layouts/_default/baseof.html=.

To publish, push the site source to the =pages= branch. GitHub Actions
builds the site in Docker and deploys it to
[[https://temmeand.github.io/elec-egr-resources/]]. In the repository
settings, configure *Settings > Pages > Build and deployment > Source*
to use *GitHub Actions*.

Push directly to =pages= to build and publish the site; no pull request
is required. The =github-pages= environment allows deployments from
=pages=.

The Dockerfile pins the Hugo release and verifies its
architecture-specific checksum, and pins ox-hugo and tomelr by commit.
Dependabot checks the Docker image and GitHub Actions pins weekly.
